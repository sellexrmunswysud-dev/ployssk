# ระบบบริหารจัดการทะเบียนคุมลูกหนี้ทางการแพทย์ โรงพยาบาลสังขละบุรี (SKB Management System)

ระบบสารสนเทศบริหารจัดการทะเบียนคุมลูกหนี้ 52 สิทธิ์การรักษาพยาบาล (ตามเอกสารทางการ รพ.สังขละบุรี) พัฒนาด้วย React, TypeScript, Vite, Tailwind CSS และเชื่อมต่อ Cloud Firestore อัตโนมัติ

---

## 🚀 ขั้นตอนการนำขึ้น Hosting ด้วย Vercel (Repository: `sellexrmunswysud-dev/ployssk`)

โปรเจกต์นี้ได้รับการตั้งค่าไฟล์คอนฟิกสำหรับ Vercel (`vercel.json`) พร้อมรองรับ Single Page Application (SPA Rewrites) และระบบ Build ของ Vite เรียบร้อยแล้ว สามารถขึ้น Vercel ได้ทันทีตามขั้นตอนดังนี้:

### วิธีที่ 1: Deploy ผ่าน Vercel Dashboard (แนะนำ - สะดวกที่สุด)
1. ไปที่เว็บไซต์ **[vercel.com](https://vercel.com)** และเข้าสู่ระบบด้วย GitHub
2. คลิก **"Add New..."** -> **"Project"**
3. เลือก Repository: `sellexrmunswysud-dev/ployssk` แล้วคลิก **"Import"**
4. ตรวจสอบการตั้งค่า (Vercel จะตรวจจับอัตโนมัติตาม `vercel.json`):
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. *(ไม่บังคับ)* หากต้องการระบุ Environment Variables ใน Vercel:
   - `VITE_FIREBASE_PROJECT_ID`: `ploy-d797f`
   - `VITE_FIREBASE_DATABASE_ID`: `ai-studio-0b5f39f1-42eb-4e7f-a501-b3844b7b6797`
   - *(หรือปล่อยว่างไว้ได้ เนื่องจากระบบมีไฟล์ `firebase-applet-config.json` บรรจุการตั้งค่าพร้อมทำงานในตัวเรียบร้อยแล้ว)*
6. คลิก **"Deploy"** รอประมาณ 1-2 นาที เว็บไซต์จะออนไลน์พร้อมใช้งานทันที!

---

### วิธีที่ 2: Deploy ผ่าน Vercel CLI บนเครื่องคอมพิวเตอร์
```bash
# 1. ติดตั้ง Vercel CLI (หากยังไม่มี)
npm i -g vercel

# 2. ทำการ Login และ Deploy
vercel

# 3. Deploy ขึ้น Production
vercel --prod
```

## 📂 โครงสร้างและฟังก์ชันสำคัญของระบบ
1. **ทะเบียนคุมลูกหนี้ 52 สิทธิ์:**
   - หมวด 1: ลูกหนี้การค้า-หน่วยงานภาครัฐ (รหัส 1102050101) 33 รายการ
   - หมวด 2: ลูกหนี้การค้า-บุคคลภายนอก (รหัส 1102050102) 19 รายการ
   - คำนวณอัตโนมัติ: ยอดตั้งต้น + ตั้งใหม่ − รับชำระ − ตัดหนี้สูญ = ยอดลูกหนี้ยกไป
2. **แดชบอร์ดสรุปภาพรวม:** การ์ด 5 หมวดหลัก, กราฟเปรียบเทียบสัดส่วน ภาครัฐ vs บุคคลภายนอก และระบบแจ้งเตือนหนี้เกิน 30 วัน
3. **ระบบพิมพ์รายงานราชการ (A4 Print):** พร้อมช่องลงนาม 3 ระดับ (ผู้รายงาน, ผู้ตรวจสอบ, ผู้อำนวยการ รพ.สังขละบุรี) และส่งออก Excel (.xls)
4. **ระบบแจ้งเตือน SMS/Email:** ส่งสรุปยอดประจำเดือนและเก็บบันทึกประวัติ (Notification Logs)
5. **ระบบจัดการสิทธิ์ผู้ใช้งาน (RBAC):** แยกสิทธิ์ ผอ.รพ., เวชสถิติ, การเงิน, ผู้ดูแลระบบ
6. **ระบบเปรียบเทียบข้อมูล (Reconciliation):** ตรวจสอบยอดผลต่างกับระบบสารสนเทศ HIS ในคลิกเดียว
7. **โหมดถนอมสายตา (Dark Mode):** ใช้งานสบายตาตลอด 24 ชั่วโมง
